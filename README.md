# Contact Form Automation

## 📌 Business Problem

Small businesses receive leads through their websites, but manually copying customer information into spreadsheets is slow and error-prone.

---

## ✅ Solution

This workflow automatically:

- Receives a contact form submission
- Validates the submitted data
- Qualifies the lead based on business rules
- Saves qualified leads to Google Sheets
- Sends an email notification

---

## 🚀 Workflow

1. Receive Lead (Webhook)
2. Parse JSON
3. Validate Country
4. Validate Budget
5. Validate Employees
6. Save to Google Sheets
7. Send Email Notification

---

## 🛠 Tech Stack

- n8n
- Webhooks
- Google Sheets API
- Gmail API
- JSON
