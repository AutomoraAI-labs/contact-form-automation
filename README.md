# Contact Form Automation

## Business Problem

Small businesses receive customer inquiries through their website, but manually copying leads into spreadsheets wastes time and can result in missed opportunities.

## Solution

This automation receives contact form submissions, validates the data, and automatically stores qualified leads in Google Sheets.

## Features

- Receive website form submissions
- Validate required fields
- Filter qualified leads
- Save leads to Google Sheets
- Ready to connect with email notifications

## Tech Stack

- n8n
- Webhook
- Google Sheets
- JSON
